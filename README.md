# Mis Tareas — Demo de colaboración en GitHub

Este repositorio es un **taller de demostración**: una mini app de tareas hecha
en Next.js/React que sirve de excusa para mostrar, con historial real, cómo es
el trabajo colaborativo en GitHub.

> El código de la app es simple a propósito. Lo importante aquí **no es la app**,
> sino el flujo: ramas, commits, Pull Requests, code review, issues y resolución
> de conflictos.

## Qué vas a encontrar en este repo

- **Issues** que describen el trabajo a hacer (como en un proyecto real).
- **Ramas de feature** (`feature/...`) donde se desarrolla cada cambio.
- **Pull Requests** que proponen fusionar cada rama a `main`, con comentarios de
  revisión.
- Un **conflicto de merge** provocado y resuelto a propósito, para que veas cómo
  se maneja.
- **Milestone**, **labels** y un **release** etiquetado (`v1.0.0`).

Revisa la pestaña **Pull Requests → Closed** y la pestaña **Issues → Closed**
para leer el historial completo.

## La app

Una lista de tareas donde puedes:

- Crear tareas nuevas.
- Marcarlas como completadas.
- Ver cuántas quedan pendientes.
- Filtrar por estado (todas / pendientes / completadas).

## Cómo correrla localmente

```bash
npm install
npm run dev
```

Luego abre http://localhost:3000
